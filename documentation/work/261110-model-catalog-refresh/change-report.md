# Change Report: Model Catalog Refresh (Fable 5.2, Haiku 5.5, GPT-6.1-Terra)

- Date: 2026-11-10
- Requested by: the owner, in chat on 2026-11-10: add Claude Fable 5.2, drop
  Claude Fable 5, and review the rest of the catalog. The owner chose to keep
  the GPT-5.6 family, to add Claude Haiku 5.5 to the picker, and to bump the
  release-train version to 2.8.2.
- Upstream feature artifacts: none. The catalog is hand-maintained in
  `packages/orchestrator/src/models.ts`; the previous refresh shipped in
  v2.6.4 (`4b52130`) and the per-model CLI minimums in v2.6.5 (`481aecc`).
- Release context: this change lands after Gate 1 of the
  [2.8–2.9 program](../release-2-8-2-9-program/tracker.md) closed on the 2.8.1
  candidate. It is not one of the program's work packages.

## What changed

1. `banzai model` picker (`SELECTABLE_MODELS`):
   - added Claude Fable 5.2 (`claude-fable-5-2`) as the current Fable;
   - added Claude Haiku 5.5 (`claude-haiku-5-5`);
   - removed Claude Fable 5 (`claude-fable-5`); Claude Fable 5.1 takes its
     previous-generation slot and description;
   - added GPT-6.1-Terra (`gpt-6.1-terra`) with `low`…`max` plus `ultra`.
2. Claude catalog:
   - `claude-fable-5-2` and `claude-haiku-5-5` are supported;
   - `claude-fable-5` is no longer supported and reports
     "superseded by claude-fable-5-2";
   - `claude-mythos-preview` now points at `claude-fable-5-2`;
   - the Haiku replacement target for retired Haiku 3.x models moves from
     `claude-haiku-4-5` to `claude-haiku-5-5`. `claude-haiku-4-5` and
     `claude-haiku-4-5-20251001` stay supported (release-policy live model);
   - new CLI minimums: `claude-fable-5-2` Claude Code 2.1.321,
     `claude-haiku-5-5` Claude Code 2.1.293. Both are newer than the
     vendor-wide 2.1.290, so the vendor preflight enforces them.
3. Codex catalog:
   - `gpt-6.1-terra` is supported, with CLI minimum Codex 0.165.0;
   - `gpt-5.5` moves from "deprecated, retires 2026-10-14" to
     "retired 2026-10-14", still replaced by `gpt-6.1-sol`.
4. Release-train version 2.8.1 → 2.8.2 (`npm run version:set -- 2.8.2`), and
   `PROJECT_MANIFEST.md` §1 records 2.8.2.

Unchanged by decision: the GPT-5.6 family stays in the picker, and Claude
Opus 5, Sonnet 5, Opus 4.8 and Sonnet 4.6 stay as earlier-generation choices.
No `fable` tier alias was added to the supported set.

## Why

Sources checked on 2026-11-10:

- Claude model deprecations page: `claude-fable-5-2` and `claude-haiku-5-5`
  are active; `claude-fable-5` is still active (not before 2027-06-09), so it
  is superseded rather than deprecated; `claude-mythos-preview` is deprecated
  without a retirement date.
- Claude Code model configuration page: "Fable 5.2 requires Claude Code
  v2.1.321 or later", "Use v2.1.293 or later with Haiku 5.5", and Fable and
  Haiku 5.5 accept `low`, `medium`, `high`, `xhigh`, `max`.
- Codex 0.166.0 bundled catalog (read from the installed binary): GPT-6.1-Terra
  with `low`…`ultra`; GPT-5.6 entries list an upgrade to GPT-6-Sol/GPT-6-Luna
  with no retirement date.
- Codex release notes: 0.165.0 is the first stable release that adds GPT-6.1
  Terra to the bundled catalog (#57337 backport, touching
  `codex-rs/models-manager/models.json`); 0.166.0 adds it to the Vertex AI and
  Bedrock catalogs. The catalog's rule is "first stable release whose bundled
  catalog carries the model", so the minimum is 0.165.0. The Codex models page
  says GPT-6.1-Terra "requires Codex CLI 0.159.0 or later" (server-delivered
  catalog); the stricter bundled-catalog floor was kept.
- Codex models page: GPT-5.5 retired from Codex with ChatGPT sign-in on
  2026-10-14; the runner is subscription-only.

The local `~/.codex/models_cache.json` (written by a 0.164.0 client) listed only
five models and was not used as evidence.
