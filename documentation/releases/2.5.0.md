# Banzai 2.5.0

Release following [2.4.0](2.4.0.md), with proportionate verification evidence
under [ADR-0043](../decisions/0043-proportionate-verification-evidence.md) and
instruction baseline evolution under
[ADR-0044](../decisions/0044-instruction-baseline-evolution.md).

## Changes since 2.4.0

- The runner and standalone verification helper use shared deterministic rules
  to select checks and assess whether prior successful evidence remains
  applicable. Explicit project policy and sufficient unchanged-input evidence
  are required for reuse; unknown or mixed scope retains applicable checks.
- Physical verification attempts remain distinct from reused evidence and
  current applicability. Missing or incomplete input capture cannot establish
  unchanged inputs, and missing execution proof keeps evaluation coverage
  incomplete.
- Accepted-finding closure guidance supports concise report updates and focused
  independent resolution review. Human triage, approved plan obligations, and
  the complete release gate remain enforced.
- Maintainers can explicitly update current instruction expectations through
  the bounded authorization procedure. Original transition evidence remains
  immutable, and generated resource and bundle parity remain exact.
- The test driver accepts repeatable `--file` selectors for focused checks;
  omitting selectors retains the complete suite and its cleanup behavior.

## Compatibility

- Existing configurations and historical runs retain their prior behavior and
  contract identities. Configuration schema 3 opts new work into the new
  verification evidence model.
- Evaluation export and KPI v2 are explicit choices; v1 remains the default.
  Historical executions are not relabeled as fresh verification.
- The plugin and orchestrator share version **2.5.0** and remain separately
  installable and deliverable. See the [getting-started guide](../getting-started.md)
  for supported hosts, runtimes, and client setup.

These notes describe release contents. Maintainers use `npm run release:check`
