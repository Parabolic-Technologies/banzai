## Included in the initial public release

- The Banzai plugin for Claude Code and Codex, with workflow skills,
  explicit approvals, architecture decisions, requirements, plans, review,
  and project guidance.
- The optional local `banzai` CLI, coordinating planning, implementation,
  deterministic verification, independent review, and human triage.
- Recovery, diagnostics, and local evaluation/reporting commands with explicit
  limits on what retained evidence can establish.
- Proportionate development plans: binding scope, behavior, constraints, and
  verification remain mandatory, while explicitly optional implementation
  guidance permits compliant alternatives. Existing approved plans retain
  their original meaning.
- Public license, usage, contribution, conduct, security, and attribution
  documents, plus GitHub-facing installation and package metadata.

The plugin and orchestrator share version **2.2.0**, but their installation and
delivery remain separate. This release preserves the existing version line.
The root workspace stays private; only the CLI package is published to npm.

## Requirements and installation

Use macOS or Linux and Node.js 22.20.0+ within major 22, or 24.11.1+ within
major 24. The orchestrator requires Git, locally installed Codex CLI 0.145.0+
and Claude Code 2.1.218+, subscription authentication, and the plugin in both
clients. Node 26 is advisory compatibility evidence, not a supported lane.

Follow the [installation instructions](../../README.md#install) for the plugin
and source-checkout development path. Install this CLI release with:

```text
npm install --global @parabolic-technologies/banzai@2.2.0
banzai --help
```

The npm package installs the CLI's runtime dependencies; the plugin and model
clients remain separate installations. The committed CLI bundle is not a
self-contained binary.

## Migration from earlier private releases

Release **1.21.0** is the last legacy-compatible instruction-layout release.
Projects using the earlier layout must explicitly invoke `project-manifest`
and approve its migration diff. An update does not migrate project files
automatically. Affected work stops until the layout is resolved. Follow the
[migration procedure](../../plugins/banzai/skills/project-manifest/references/layout-migration.md).

## Verification and support

Maintainers use `npm run release:check` for deterministic source validation.
GitHub Actions runs that gate in the required `release_check_node_22` and
`release_check_node_24` jobs; Node 26 forward compatibility and explicitly
enabled live vendor checks are advisory. Local checks do not establish hosted
CI, public installation, or real vendor permission behavior. Delivery evidence
is recorded in the [delivery record](public-publication.md#delivery-record).

Report ordinary bugs through
[GitHub Issues](https://github.com/Parabolic-Technologies/banzai/issues), and
vulnerabilities privately through [SECURITY.md](../../SECURITY.md).
