# Banzai 2.4.0

Release following [2.3.0](2.3.0.md), with runner-delivered phase instructions
under [ADR-0042](../decisions/0042-runner-delivered-phase-instructions.md).

## Changes since 2.3.0

- The orchestrator includes phase instructions and shared policy bodies in
  each model request, including resumed sessions, retries, and recovery calls.
  Standalone skills consume the same maintained guidance.
- Scoped Claude invocations compare installed instruction resources with the
  bundle before model attempts. Confirmed mismatches stop with
  `INSTRUCTION_RESOURCE_MISMATCH` while preserving saved decisions and
  checkpoints. Ambient mode and unresolved resource identities remain
  unverifiable.
- Context accounting includes the complete dispatched instruction payload.
  Progress output describes the phase being executed and retains actual
  client-reported skill activity.
- Strict accepted-finding fixes can write the existing bound change report
  when the report rule requires it, alongside implementation and test reports.
  Other phase grants retain their existing scope.

## Compatibility and migration

- `banzai doctor --json` emits `banzai-doctor/v3` with `schemaVersion: 3`.
  The new `claude.instructions` check appears after `claude.environment` and
  before `claude.permissions`. Update consumers that require the v2 contract;
  historical reports retain their original identity.
- Update the plugin and orchestrator together. For an instruction-resource
  mismatch, rebuild the source bundle or update the installed plugin to the
  matching release. Explicit ambient mode remains available with unverifiable
  instruction parity.
- Existing workflow approvals, artifact bindings, report ownership, and
  human review gates retain their meaning. Standalone skill invocation remains
  available.

## Requirements and installation

Supported hosts are macOS and Linux. Node.js 22.20.0+ within major 22 or
24.11.1+ within major 24, Git, and supported subscription-authenticated Codex
and Claude Code clients are required. See the
[getting-started guide](../getting-started.md) for client and plugin setup.

```text
npm install --global @parabolic-technologies/banzai@2.4.0
banzai --help
```

The plugin and orchestrator share version **2.4.0**; their installation and
delivery remain separate. Maintainers use `npm run release:check` for
deterministic source validation. Verified publication facts belong in the
[delivery record](public-publication.md#delivery-record).
