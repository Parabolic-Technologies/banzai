# Banzai 2.2.2

Patch release following [2.2.1](2.2.1.md).

## Changes since 2.2.1

- GitHub Releases publish the CLI package to npm through trusted publishing,
  as defined by [ADR-0039](../decisions/0039-npm-trusted-publishing-on-github-release.md).
  The workflow checks that the tag matches the source version, runs the
  deterministic release gate, skips versions already on npm, and verifies
  registry metadata after publication.
- The [publication procedure](public-publication.md) documents trusted
  publisher setup, the manual fallback, and delivery evidence.

CLI behavior, commands, configuration schemas, and persisted formats are
unchanged. Projects on 2.2.1 need no migration.

## Requirements and installation

Requirements are unchanged from [2.2.1](2.2.1.md#requirements-and-installation):
macOS or Linux, Node.js 22.20.0+ within major 22 or 24.11.1+ within major 24,
Git, Codex CLI 0.145.0+, Claude Code 2.1.218+, subscription authentication,
and the plugin in both clients.

```text
npm install --global @parabolic-technologies/banzai@2.2.2
banzai --help
```

The plugin and orchestrator share version **2.2.2**; their installation and
delivery remain separate. Maintainers use `npm run release:check` for
deterministic source validation. Verified publication facts belong in the
[delivery record](public-publication.md#delivery-record).
