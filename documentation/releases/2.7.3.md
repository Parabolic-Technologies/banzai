# Banzai 2.7.3

Refreshes the primary and npm README pages, documentation navigation, and
getting-started guide.

The logo asset family now uses the Parabolic icon across the light, dark and
adaptive horizontal logos, standalone icon, avatars and social preview.
Horizontal logos retain the Banzai wordmark, "Spec-Driven AI Development"
tagline and theme-appropriate text colours. The social preview retains its
lettering and uses a matching blue-to-magenta accent.

PNG exports are regenerated at their existing 192×192, 256×256, 512×512 and
1280×640 sizes. The asset guide documents the updated formats, palette and usage.

No workflow, configuration or data migration is required.
