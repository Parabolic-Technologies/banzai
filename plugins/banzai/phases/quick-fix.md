# Lite Quick-Fix Phase

Apply fix and manifest guidance to the selected original request. Use the
supplied work identity and bounded scope; do not infer additional accepted review
findings. Make the smallest compatible code, test or documentation change that
satisfies the request and its existing authority.

Run proportionate verification and apply the unchanged conditional Report Rule.
Write the exact supplied changeReport role only when that rule requires it; a
grant alone creates no report requirement. This route creates no strict ledger.
Escalate a newly required decision before dependent work and preserve existing
report accuracy, architecture and permission boundaries.
